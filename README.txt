millsage · 重逢的间隙

体验说明
左侧：泽海奏多。点击后右侧萤化作白羽向上飘散，进入奏多版原版车库。
右侧：汐见萤。点击后左侧奏多化作玻璃向下坠落，进入萤版原版车库。
点击车库钢琴前的目标角色，或右下角返回按钮 / Escape，以时空扭曲返回主页。
右上角可以暂停动态、全屏、查看素材说明。

本地启动
需要 Node.js 18 或更新版本。在本目录运行：
  node serve.mjs
然后打开 http://127.0.0.1:8765
必须通过 HTTP 服务打开，不能直接双击 index.html（浏览器模块与模型加载限制）。

部署
dist/ 是完整静态网站，无需 npm install 或构建，部署整个 dist 目录即可。
全部必要模型、贴图、动作、背景和运行时已经随包保存。
首次加载约 33 MB；进入车库时再加载对应场景。支持 WebGL 的现代浏览器。

资源说明
车库使用游戏原始 Spine home_start 动作，每轮后停留再重播。
主页使用原始 Live2D 模型，网页控制同步呼吸与眨眼。
羽毛、玻璃与返回转场为本网站编排。
萤版素材导出的背景可见性状态在 garage-loader.js 内按原始 hide 列表恢复。
原始场景 JSON 保持不变。
完整来源与许可证见 dist/credits.txt 和 dist/assets/immersive/SOURCES.txt。
